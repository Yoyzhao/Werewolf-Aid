## 一、总览：狼人杀的规则家族

### 1.1 核心框架（所有套系共享）

狼人杀是一款**阵营对抗的社交推理游戏**。一局游戏由中立的"法官/上帝（Host）"主持，玩家被秘密分配身份，分为三大阵营。游戏在**夜晚**与**白天**两个阶段交替进行：

- **夜晚**：特殊角色依次睁眼行使技能；狼人阵营共同选择击杀目标。
- **白天**：公布死讯、竞选警长（通常仅首日）、依次发言、投票放逐一名玩家。
- 循环直至某一阵营达成胜利条件。

### 1.2 三大阵营

| 阵营 | 构成 | 典型胜利条件 |
| --- | --- | --- |
| **好人阵营** | 平民（无技能）+ 神职（预言家、女巫、猎人、守卫等） | 放逐/杀死**所有狼人阵营玩家** |
| **狼人阵营** | 普通狼人 + 特殊狼（狼王、白狼王、隐狼等） | **屠边**：杀光所有神职**或**所有平民；或**屠城**：杀光所有好人 |
| **第三方阵营** | 由特定身份触发（丘比特人狼恋情侣、吹笛者、盗贼等） | 各自独立的胜利条件，通常需消灭场上其余所有阵营 |

### 1.3 六套规则体系一览

| 套系 | 核心特征 | 典型板子 | 主要流行场景 |
| --- | --- | --- | --- |
| **一、标准竞技局** | 四神四民四狼、警长竞选、屠边判定 | 12人预女猎守 / 预女猎白 | 面杀与网杀主流、比赛 |
| **二、狼王/白狼王局** | 狼人阵营获得"死后开枪/自爆带人"能力 | 12人狼王守卫、白狼王守卫 | 网易官方场、竞技 |
| **三、丘比特情侣局** | 首夜连情侣，人狼恋触发第三方 | 含丘比特的情侣板 | 娱乐局、面杀 |
| **四、新月事件卡局** | 每晚/首夜抽事件卡，临时或永久改变规则 | 36张事件卡局；网易"新月降临" | 娱乐局、派对 |
| **五、身份转换与第三方扩展局** | 盗贼换牌、野孩子变狼、吹笛者独立获胜等 | 盗贼/野孩子/吹笛者板 | 面杀大型牌池 |
| **六、扩展角色池** | 大量神职/狼人/第三方特殊角色自由搭配 | 16人以上大局 | 面杀、网易官方娱乐场 |

## 二、通用核心机制

以下机制在多数套系中通用，是理解各变体的基础。

### 2.1 一局流程

```
分发身份 → [首夜（含特殊角色先手）] → 首个白天（警长竞选）
   → 发言 → 投票放逐 → 夜晚 → 白天 …… → 达成胜利条件
```

### 2.2 夜间行动顺序（标准参考顺序）

具体顺序随板子增减角色而调整，法官按固定顺序依次唤醒：

1. **盗贼**（如使用，仅首夜）——选择替换身份
2. **丘比特**（如使用，仅首夜）——指定情侣
3. **情侣**（如使用，仅首夜）——相互确认，不看身份牌
4. **守卫**——选择守护目标
5. **预言家**——选择查验目标
6. **狼人**——确认同伴，协商选择击杀目标（可空刀、自刀）
7. **女巫**——获知被刀目标，选择用药或不用
8. **吹笛者/其他扩展角色**（如使用）

> 注：网易官方网杀的常见播报顺序为「守卫 → 狼人 → 预言家 → 女巫 → 猎人确认开枪状态」，与面杀略有差异。

### 2.3 白天流程

1. **公布死讯**：法官宣布昨夜死亡玩家（部分板子不公布身份）；若无人死亡，宣布"平安夜"。
2. **遗言**：死亡玩家发表遗言（规则依板子而定，见第九章）。
3. **警长竞选**（通常仅首日，见 2.4）。
4. **发言**：存活玩家按警长指定顺序（或死左/死右顺序）依次发言；禁止贴脸、聊场外。
5. **投票放逐**：同时举票，得票最多者出局；平票则 PK 发言后复投，再平票则本轮无人出局（或警徽流失，依阶段而定）。

### 2.4 警长与警徽机制

| 项目 | 规则 |
| --- | --- |
| 竞选时机 | 首个白天、宣布死讯前；自愿上警者为"警上"，其余为"警下" |
| 投票权 | 警上玩家**无**被选举权以外的投票权（不可投警长票）；警下玩家投票 |
| 发言与退水 | 警上玩家依次发言，投票前可"退水"，退水后失去选举权 |
| 当选 | 得票最多者成为警长，获**警徽** |
| 警长权力 | 放逐投票计 **1.5 票**；**最后发言**；决定当日发言顺序（归票权） |
| 平票 | 平票者 PK 发言后复投；再次平票则**本局无警长** |
| 自爆吞警徽 | 竞选期间狼人自爆→本局无警徽；若需二次吞警徽需再安排一名狼人自爆 |
| 警徽处置 | 警长阵亡可"交警徽"（指定继任者）或"撕警徽"（本局不再有警长） |

### 2.5 胜负判定

- **好人胜**：所有狼人阵营玩家出局。
- **狼人胜**：
  - **屠边**（12人标准局通用）：所有**神职**出局，或所有**平民**出局。
  - **屠城**：所有好人阵营玩家出局（部分板子/快速判定：白天结束时狼人数量 ≥ 好人数量）。
- **第三方胜**：依触发身份的独立条件（如丘比特人狼恋需消灭所有非第三方玩家）。

> 因常见屠边规则要求神、民、狼数量相对均衡，游戏人数一般为 **3 的倍数**；10 人以上板子通常设警长。

### 2.6 通用约束与术语

| 术语 | 含义 |
| --- | --- |
| 贴脸 / 聊场外 | 发言中以场外信息、情绪发誓等方式佐证身份，通常被禁止 |
| 跟票 | 非同时举票、跟随他人投票，通常判无效 |
| 弃票 | 投票阶段可选择不投 |
| 悍跳 | 狼人冒充预言家等神职身份 |
| 自刀 | 狼人夜间选择击杀自己队友，以骗取女巫解药或制造身份错觉 |
| 倒钩 / 冲锋 / 深水 | 狼人伪装策略：假装支持真预言家 / 支持悍跳队友 / 隐藏不惹眼 |

## 三、套系一：标准竞技局（预女猎守 / 预女猎白）

这是当前最主流、最平衡的竞技套系，也是其他变体的基础。

### 3.1 板子配置（12人）

| 版本 | 神职（4） | 平民（4） | 狼人（4） |
| --- | --- | --- | --- |
| **预女猎守** | 预言家、女巫、猎人、守卫 | 4 平民 | 4 狼人 |
| **预女猎白** | 预言家、女巫、猎人、白痴 | 4 平民 | 3 狼人 + 1 白狼王 |
| （网易标准场示例） | 预言家、女巫、猎人、守卫 | 4 平民 | 3 狼人 + 1 狼王 |

> 其他人数常见配置：6人（2狼2民预言家+女巫）、8人（3狼3民预言家+女巫）、9人（3狼3民预女猎）、10人（3狼4民预女猎）、11人（4狼4民预女猎）等。

### 3.2 核心角色技能与限制

| 角色 | 技能 | 关键限制 |
| --- | --- | --- |
| **狼人** | 夜间共同击杀一人 | 意见不一致则当夜无人死亡；可空刀/自刀 |
| **平民** | 无技能 | 依靠发言与投票找狼 |
| **预言家** | 每夜查验一人是"好人/狼人" | 只能判阵营，不能得知具体身份（神职或平民） |
| **女巫** | 解药救当夜被刀者；毒药毒杀一人 | **每夜至多用一瓶、同夜不可两瓶**；面杀首夜可自救，网杀通常不可自救 |
| **猎人** | 被狼刀或被投票放逐时，可开枪带走一人 | **被毒杀、被白狼王自爆带走、殉情时不能开枪** |
| **守卫** | 每夜守护一人免疫狼刀 | **不可连续两夜守护同一人**；与女巫解药同用一人则该目标死亡 |
| **白痴** | 被投票放逐时翻牌免死，留在场上继续发言 | 翻牌后**失去投票权**；被狼刀、毒杀、猎人带走仍会死亡 |

### 3.3 关键冲突判定

- **同守同救**：守卫守护的对象与女巫解药救活的对象为同一人时，该玩家**仍然死亡**（解药与守护冲突）。
- **女巫用药限制**：解药仅能救"当夜被狼人击杀"的玩家；每瓶药限用一次，同一夜晚最多使用一瓶。
- **猎人开枪条件**：仅当死于狼刀或白天放逐；被女巫毒死、殉情、白狼王自爆带走则技能失效。

## 四、套系二：狼王 / 白狼王局

在标准局基础上，赋予狼人阵营"死亡后仍可带人"的强力机制，增强狼人反转能力。

### 4.1 两种特殊狼

| 角色 | 技能 | 限制 |
| --- | --- | --- |
| **狼王（狼枪）** | **死亡后开枪**带走一名玩家 | 被猎人带走仍可开枪；**被毒杀、殉情不能开枪** |
| **白狼王** | **白天自爆**时选择带走一名玩家 | 非自爆出局（被毒、被投票、夜间死亡）无法发动；若为场上最后一只狼，技能通常失效 |

### 4.2 特殊机制

- **自爆**：狼人在白天发言阶段（或竞选阶段）主动暴露身份并出局，立即中止当前流程、直接进入夜晚。
- **吞警徽**：警长竞选期间狼人自爆，本局无警徽；若狼队想连续压制，需第二天再安排一名狼人自爆（"双爆吞警徽"）。
- **带人判定差异**：网易规则中，猎人被狼王带走**可以**开枪反击（互带）；被女巫毒死则不能。

## 五、套系三：丘比特情侣局（第三方阵营）

丘比特通过"连情侣"引入变量，是第三方阵营最经典的实现。

### 5.1 规则要点

| 环节 | 规则 |
| --- | --- |
| 连情侣 | 首夜丘比特指定**任意两名玩家**（可包含自己）成为情侣，二人相互确认但**不可互看身份牌** |
| 殉情 | 情侣中一方死亡，另一方**立即殉情出局**（部分变体在"愚人节"事件卡当天不殉情） |
| 投票限制 | 情侣**不可互投** |
| **人狼恋** | 若情侣分属好人与狼人阵营，则二人 + 丘比特组成**第三方阵营**，胜利条件变为"消灭除第三方外的所有玩家" |
| 同阵营恋 | 若情侣同属好人（或同属狼人），则不触发第三方，仍随原阵营胜负 |

### 5.2 特殊判定

- 第三方情侣若一方死亡，另一方仍按殉情规则出局。
- 人狼恋触发后，原好人/狼人阵营的胜利条件不再包含第三方成员，需将其一并消灭。

## 六、套系四：新月事件卡局（New Moon）

这是最具"规则改写"色彩的套系：通过事件卡在局中动态改变规则，带来高度不确定性。

### 6.1 经典（桌面）新月规则

- **组件**：36 张事件卡，洗匀后牌面向下置于桌面中央。
- **触发时机**：每个夜晚结束后、天亮时，由**上一个死亡玩家**翻开牌堆顶端一张事件卡并大声读出，全场按卡面说明改变规则。
- **三类卡片时效**：

| 卡面标记 | 含义 | 时效 |
| --- | --- | --- |
| **圆月** | 立即发生的事件 | 临时，发生即失效 |
| **弯月** | 不立即发生（延迟触发）的事件 | 临时，发生即失效 |
| **黑色无月** | 永久生效的事件 | 一直有效至游戏结束 |

- **开局预设**：游戏开始前，法官可选择若干永久效果卡，使特定事件在开局即发生。

**新月规则下的经典角色补充**（部分仅在新月板出现）：

| 角色 | 技能 |
| --- | --- |
| **吹笛者** | 每晚迷惑两人；当所有存活者均被迷惑时，吹笛者单独获胜 |
| **替罪羊** | 白天投票平票时替罪羊死；其死亡时可指定谁有/无投票权 |
| **长老** | 两条命，被狼刀两次才死；若被好人投票误杀，所有神职变为平民；被女巫救只恢复一条命 |
| **魔术师** | 夜间先手，每晚交换两名玩家的号码牌，当晚有效 |
| **恶灵骑士** | 夜间随狼人行动，不可自爆、不会夜间死亡；一次性反伤：被预言家查验则次日预言家死；被女巫毒则次日女巫死 |
| **丘比特（新月版）** | 连情侣；"愚人节"事件卡发动当天，情侣必须互相指控，且不殉情 |

**经典事件卡示例**：
- **愚人节**：情侣必须互相指控对方，当日一方死亡另一方不殉情（效果当天结束）。
- **去林地采集**：女巫可恢复一瓶药剂。

### 6.2 网易"新月降临"现代版（2025 年上线）

- **定位**：12 人限时娱乐板子，基于 **12人预女猎愚**（愚者）板加入随机事件。
- **触发**：**首夜角色行动完成后、天亮之前**，随机触发**一次**新月事件，并公布事件内容。
- **事件类型**（五类）：娱乐事件、信息事件、结算事件、技能事件、身份转换事件。
- **效果强度示例**：可能使某神职直接出局从而狼人直接获胜；或从第二夜起所有角色获得增益、可释放两次技能（"大乱斗"）。

> 经典新月与网易"新月降临"是同一思路的两种实现：前者每夜翻卡、持续改写；后者每局一次、事件更强。

## 七、套系五：身份转换与第三方扩展局

这类变体通过"开局换牌"或"条件变身"引入阵营的不确定性。

| 角色 | 首夜/条件技能 | 阵营与胜利条件 |
| --- | --- | --- |
| **盗贼（窃贼）** | 开局额外加入两张平民牌；首夜从两张备用牌中择一替换自己的身份；**若两张均为狼人则必须选择狼人** | 随所选身份牌；一局中不可重复偷取同一玩家 |
| **野孩子** | 首夜选择一名"崇拜者"；崇拜者出局后，野孩子于下一个白天或夜晚**加入狼人阵营**，此后每夜参与杀人 | 第三方；变身判定**滞后于**游戏结束判定（若崇拜者死亡即达成某阵营胜利，则按该阵营结算）；野孩子先于崇拜者死亡则永远属好人阵营 |
| **吹笛者** | 每晚迷惑两人（被迷惑者被通知） | 独立第三方；所有其他存活者均被迷惑时单独获胜 |
| **失踪的宝物/类似角色** | 一局中不可重复偷取同一玩家 | 第三方；当好人与狼人存活人数均 ≤ 1 时获胜 |

## 八、套系六：扩展角色池速查

面杀大型牌池与网易官方娱乐场包含大量扩展角色，以下按阵营归类，供搭建自定义板子时参考。

### 8.1 好人阵营扩展

| 角色 | 核心机制 |
| --- | --- |
| **守卫** | 每夜守护一人免疫狼刀，不可连续两夜守同一人；与女巫解药冲突同守同救致死 |

### 8.4 机械狼通灵师板子（网易 App 新玩法，约 2025 年推出）

**机械狼**是狼人阵营的特殊"功能狼"，被称为狼队"大哥"。因其在夜间**单独行动、与普通狼人互不知晓身份、且能复制他人技能**，"机械狼通灵师"板子的最大特点是**金水、银水都不一定是好人**，逻辑不确定性极高。

**板子配置（12 人局）**

| 阵营 | 角色 |
| --- | --- |
| 好人阵营 | 通灵师 1、女巫 1、猎人 1、守卫 1、平民 4 |
| 狼人阵营 | 普通狼人 3、机械狼 1 |

> 其中"通灵师"相当于本板子的预言家：每晚可查验一名玩家的**具体身份**（而非仅好人/狼人）。

**机械狼核心机制**

| 项目 | 规则 |
| --- | --- |
| 阵营/人数 | 狼人阵营，1 人 |
| 行动方式 | 夜间单独行动，不与普通狼人睁眼见面、互相不知身份；**不能自爆** |
| 狼刀继承 | 其他 3 名普通狼人全部死亡后，机械狼才获得狼刀；从第二晚起知晓自己是否带刀 |
| 核心技能"学习" | 全局**仅一次机会**，可在任意一晚开始时学习一名玩家，得知其真实身份并**永久习得对方技能**直至游戏结束 |

**"学习"不同对象获得的技能**

| 学习对象 | 获得技能 |
| --- | --- |
| 平民 | 无任何技能 |
| 通灵师 | 从下一晚起，每晚可查验一名玩家的具体身份 |
| 女巫 | 获得一瓶毒药，下一晚起可毒杀一名玩家 |
| 守卫 | 获得一次守护技能，下一晚起可守护一名玩家（免疫狼刀与女巫毒药，仅一次） |
| 猎人 | 从当晚起，出局时可开枪带走一人 |
| 狼人 | 获得一次"双刀"技能（须先继承狼刀方可使用）：连续两晚刀同一人可无视女巫解药与守卫守护直接杀死 |

**查验判定（通灵师验机械狼）**

- 已学习的机械狼：通灵师查验结果显示为其**所学习的身份**（如学了女巫则显示为女巫）——即"偷天换日"，这就是"金水/银水不一定是好人"的原因。
- 未学习的机械狼：查验结果显示为狼人（部分线下局约定以特殊手势表示）。

**玩法要点**（出处资料中的通行思路）

- 首夜学或不学各有利弊：不学易被通灵师首验直接暴露；多听一两轮发言再学则更易抿准身份。
- 学到通灵师可起跳给真通灵师发查杀，或选择倒钩；学到女巫可在真女巫未跳时毒掉对方；学到猎人可转为"狼枪"打法。
- 因与普通狼人互不相认，常出现普通狼人误刀机械狼的情况，局势反转频繁。

## 九、版本差异对照（面杀 vs 网杀）

| 差异项 | 面杀（经典/桌面） | 网易官方网杀 |
| --- | --- | --- |
| **女巫自救** | 首夜通常**可以**自救 | 通常**不可**自救（依板子说明） |
| **胜负口径** | 常见屠边；也有屠城板 | 标准场多为屠边 |
| **身份牌公开** | 多为明牌局（死亡翻牌） | 常见"暗牌局"（出局不翻身份） |
| **遗言规则** | 首夜死亡者有遗言；其后夜间死亡无遗言；白天死亡均有遗言（依板子） | 首夜有遗言；夜晚后续无遗言；白天死亡均有遗言；狼人自爆有 30s 遗言 |
| **发言/投票时长** | 由法官控制 | 有固定计时（如发言 120s、警长 150s、投票 15s） |
| **警长竞选** | 10 人以上常见 | 标准场通常设警长 |
| **狼王被猎人带** | 部分规则允许互带 | 明确：被猎人带走**仍可开枪**；被毒/殉情不能 |
| **新月事件** | 36 张事件卡、每夜翻卡 | "新月降临"：每局一次随机事件 |
