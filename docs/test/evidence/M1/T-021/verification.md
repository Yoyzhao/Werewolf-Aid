## 发现与修复

| 问题 | 初测结果 | 修复 | 复测 |
| --- | --- | --- | --- |
| 次要文本对比度不足 | `--faint` 在卡片/底板为 3.68–4.30，低于 4.5 | 令牌 `--faint` / `--color-faint` 由 `#6b7688` 调整为 `#808b9c` | 首页/设置/助手对比度失败项 0 |
| 开关触控过小 | Radix 开关 48×28 | 触控区改为 56×44，轨道视觉保持 48×28 | 0 |
| 轮次按钮宽度不足 | “下一轮” 38×44 | `.btn.ghost` 增加 `min-width: 44px` | 0 |
| 存活座位在 320 过窄 | 6 列时单格 37×44 | <390 宽度改为 4 列，≥390 为 6 列 | 0 |
| 投票筹码过小 | 42–48×36 | `.ballot-chip` 最小 44×44 | 0 |
| 标签最小宽度不足 | 单字自定义标签可能 <44 | `.tag` 最小 44×44 | 0 |
| 引导进度 ARIA 不合规 | `aria-label` 用于无 role 的 div，Lighthouse 可访问性 96 | 增加 `role="group"` | 可访问性 100 |

修复后：lint、format:check、typecheck、96 个单元/组件测试、13 个 e2e 全部通过；首屏 JS 108.51 kB gzip。
