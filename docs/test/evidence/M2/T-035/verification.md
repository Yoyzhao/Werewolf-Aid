## 4. 关键设计决定

1. 玩家端只读，无底部 Tab；主持端联机面板为可选层，关闭后回到 P0 单机主持。
2. 身份默认遮罩；私有字段（查验/药剂/守护/狼队友）仅本人；`revealedRoles` 仅结算后出现。
3. 连接降级文案明确“不要刷新页面”，3 次重连失败切 5s 轮询，恢复后按版本补齐。
4. 时间线按可见性拆分：主持完整、玩家公开+本人私有；不在前端裁剪他人数据。
5. 笔记默认不进入 AI 上下文，需用户主动“引用到自由描述”。
6. PWA 只缓存应用壳/静态资源/规则；不缓存 `/api`、AI、WS。
