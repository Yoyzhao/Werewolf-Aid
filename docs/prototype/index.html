      角色

      预言家 / 女巫›
      预言家：每夜查验一人「好人/狼人」，不知具体身份；仅查验者可见。
      女巫：每夜至多一瓶；解药仅救当夜被刀者，首夜可自救（可关）；同守同救目标死亡；空刀不可解药。
      守卫 / 猎人 / 白痴›
      守卫：每夜守一人免疫狼刀；不可连守；可自守；不防毒。
      猎人：被刀/被放逐可开枪；被毒/被白狼王带走不可开枪。
      白痴：被放逐翻牌免死，保留发言，失去投票权，不再成为放逐目标。
      白狼王 / 普通狼›
      白狼王：白天自爆时带走一人；非自爆出局不可发动；若为最后一狼，自爆不带人。
      普通狼：共同击杀一人；可空刀/自刀；意见不一致按空刀。
