## [CHG-20261125-01] PC 端响应式适配

- **类型**：修改
- **日期**：2026-11-25
- **功能说明**：原 PRD v1.3.1 口径为“移动端优先、桌面/平板仅兼容，不做桌面专属布局”→ 调整为：移动端仍为主设计与验收基线；PC 增加宽屏响应式布局（≥1024px 双栏/多栏、鼠标 hover 反馈、键盘可操作），不新增 PC 专属流程、页面或大屏投屏/公屏模式。
- **目标里程碑/版本**：M1 / v1.3.1（P0 范围内补充适配，不新增业务功能）
- **原交付版本/关联旧任务**：无（首轮开发）
- **技术说明文档**：docs/plan/tasks/M1/STEP-5A.md（T-013/T-025 所属阶段文档，PC 视图要求写入两任务范围）
- **来源**：用户需求（“除移动端，也要考虑到 PC 端”）；追问确认选择“响应式适配”，不需要大屏投屏
- **原因**：主持人可能使用笔记本/台式机浏览器主持，需保证 PC 下布局可用、不错版
- **影响范围**：`apps/web` 布局层（Tailwind 断点）、5A/5B 原型与状态清单、AC-16 增加 PC 抽查项；不改 PRD 业务规则、接口、数据模型
- **候选优先级**：P0（随 M1 交付）
- **受影响任务**：T-013、T-025（5A）；T-021（5C 兼容终检）
- **关联需求/决策/Bug**：PRD v1.3.1 §7.6/AC-16（以本 CHG 为增量补充）
- **验收标准**：1440×900 与 1920×1080 下：无横向滚动、不错版；主持端为双栏（步骤卡 + 座位/状态区）或单列居中（≤720px 内容宽）；助手端为双区并列；所有主操作可鼠标完成；键盘 Tab 可达；移动端 360/430 布局与 AC-16 不受影响
- **验证证据**：待验证（5A 原型走查 → T-021 终检）

- **变更决策**：已确认（用户 2026-11-25）
