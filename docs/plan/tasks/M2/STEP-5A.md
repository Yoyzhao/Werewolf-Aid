## T-035 P1 交互与页面设计

### 目标与边界

**目标**：在 P0 视觉与交互基础上，冻结 P1 页面结构、状态、文案与数据形状，供 5C/5D 直接实现。

**范围内**：联机主持端（创建/配对码/二维码/绑定确认/解绑/主持恢复/结算删除）、玩家加入与视图、连接状态与降级提示；复盘时间线；术语表/搜索；私人笔记；AI 输入过滤提示；PWA 安装/离线提示；320–440 与 1440 布局。

**范围外**：代码实现、后端契约变更、P2 功能。

### 实施步骤

1. 对照 PRD P1-1～P1-8 与 AC-12～AC-15/19 列出页面/状态清单。
2. 输出 P1 交互契约（追加到 interaction-spec v1.2）：路由、组件、状态矩阵、文案、权限可见性、失败与降级。
3. 更新 `docs/prototype/M2/index.html`：主持端房间面板、玩家加入/等待/身份视图、时间线、术语搜索、笔记、PWA 提示。
4. 走查 320/360/390/430/1440、遮罩/断网/重连/越权提示；提交用户评审。

### 验证与验收

- P1 每个页面具备加载/空/成功/失败/无权限/重复提交状态。
- 联机设计不改变 P0 单机流程；P0 页面无回归。
- 产出：interaction-spec v1.2、M2 原型；证据：评审记录与截图。

### 风险与恢复

- 设计过度：优先复用现有组件与视觉；只补联机差异。
- PWA/微信限制：在设计中明确降级提示，不承诺所有浏览器可安装。

### 完成结果（2026-11-26）

- **实际产出**：[interaction-spec v1.2](../../../tech/interaction-spec.md) 第 14～20 节；[M2 原型](../../../prototype/M2/index.html)；[T-035 报告](../../../test/evidence/M2/T-035/verification.md)。
- **覆盖**：P1-1～P1-8、AC-12～AC-15/19；主持端/玩家端/时间线/术语/笔记/AI 过滤/PWA。
- **走查**：390/320/1440 无横向滚动、无 console 错误；确认绑定/快照/身份遮罩/时间线切换/术语搜索/笔记保存/离线切换均通过。
- **待确认**：联机入口位置、加入页分享文案、笔记引用交互；用户验收后进入 5C/5D 实现。
