## T-045 P1 系统联调与 AC-12～15/19 验收

### 目标与边界

**目标**：证明 P1 联机在真实浏览器与后端上满足权限、时效、版本与删除要求。

**范围内**：
- AC-12：扫码/输码加入，正常 2s 内看到公开快照；轮询降级 5s 内；断线重连恢复。
- AC-13：DevTools/直接调 API 尝试读取他人身份或夜间信息，只能拿到自己的视图；服务端拒绝越权。
- AC-14：结算/解散后检查数据库，房间/座位/状态/快照删除。
- AC-19：连续写入旧 `version` 被 409 拒绝；玩家只接收递增版本；重连补齐。
- AC-15 的 PWA 离线冷启动由 T-046 执行，T-045 验证联机部分。

**范围外**：全量回归与性能压测（T-046）。

### 验证与验收

- 每条 AC 有可复现步骤、原始输出/截图与结论；AC-13 不以“前端隐藏”作为通过。
- 无 P1 阻断缺陷；P0 主链路回归通过。
- 产出：P1 联调报告；证据：`docs/test/evidence/M2/T-045/verification.md`。

### 风险与恢复

- 两浏览器会话时序不稳定：用固定夹具与显式等待；必要时补自动化。
- 数据删除验证：使用 SQLite 查询与 API 复核。
