## 已确认决策

1. 规则口径以 PRD 附录 A 为准；预女猎白 = 3 狼 + 1 白狼王，预女猎守 = 4 普通狼。
2. 警长竞选首日死讯前；补警徽流转、弃票、白痴无票、自爆 P0。
3. v1.3 单机主持 P0；配对码联机 P1 可选增强。
4. 平台改为 Web 应用（移动端优先 H5），不使用微信小程序/云开发；默认前后端分离，允许全栈；部署在服务器。
5. 无账号体系；匿名会话 + 房间令牌；会话 Cookie 为 httpOnly + Secure + SameSite。
6. P1 联机使用 WebSocket 推送 + 服务端视图过滤 + 5s 轮询降级。
7. 狼队友身份不做服务端同步，主持人当面组织互认。
8. AI 定位为“信息整理 + 可疑对象 + 建议 + 依据”；独立模式补局势录入；Key 默认不持久化、不落库、不写日志。
9. 移动端优先：主流 1080p 手机 + 5G/Wi-Fi 为主；CSS 360–440px（主设计 360；320 兼容地板；DPR 2.5–3）；触控 ≥44px、单手拇指区、100dvh/safe-area、无 hover 依赖；320px/4G 仅兼容降级。
10. 主持端 P0-12 屏幕常亮（Wake Lock，iOS Safari 18.4+；fallback）；性能预算首屏 JS ≤250KB、5G 首屏 ≤2s、可交互 ≤3s、主流 60fps。
11. 设备矩阵：iPhone 390/393/430/440、Android 360/384/412（1080p/DPR 2.5–3）；Chrome/Safari 主测，UC/QQ 抽查，微信内置浏览器单独真机。
12. 调研基线（2026-11，附录 G）：FHD+ 1080p 主流、120Hz Android 约 49%、5G 中位下行 216.48 Mbps/延迟 40ms、Chrome 52.39%/Safari 24.47%/UC 10.26%。
