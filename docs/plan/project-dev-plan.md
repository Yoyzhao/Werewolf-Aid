## 大致功能点

### M1 v1.3.1（P0）

- 5A/5B：移动端优先 + PC 响应式原型（主持闭环、助手/规则）、交互细化、状态与契约冻结。
- 5C：工程脚手架、共享 `game-engine`（配置/状态机/冲突胜负）、主持端流程（开局发牌/夜间白天/投票结算）、个人助手、规则内容、移动端性能/兼容。
- 5D：Fastify API、匿名会话/CSRF、AI 中转、静态服务与健康检查。
- 6：AI 前端接入与前后端整合。
- 7：系统联调与 P0 验收（AC-1～AC-11、AC-16～AC-18）。
- 8：测试用例与全量回归。
- 9：Node 单进程部署、TLS、静态/API、备份与上线准备。
- 任务数：19（T-013、T-025、T-014、T-015、T-026～T-032、T-018、T-021、T-034、T-019、T-020、T-022～T-024）。
